# Неклассические логики — практическое задание (МАИ)

Комплекс **«Нечёткие величины N(a, σ)»**: моделирование нечётких величин с гауссовой μ(x), α-отсечение, k-means, фильтры **β/γ** перед повторной кластеризацией.  
Вариант: **нормальная функция принадлежности**, реализация на **Go**, интерфейс **React**.

Полная теория, формулы, руководство и примеры — в пояснительной записке:

`fuzzy-normal/docs/Пояснительная_записка.docx`

## Запуск

```bash
cd fuzzy-normal
make
```

Браузер: **http://localhost:8080**

Типовой сценарий: **Генерация** (100–300 N) → **Кривые и α** → **Кластеры** (k-means, затем ползунки β и γ в блоке «После фильтра»).

Docker: `make up` (см. `fuzzy-normal/README.md`).

## Кратко по смыслу

1. Генерируется множество **N(a, σ)**; каждая — гауссова μ(x)=exp(−((x−a)/σ)²).
2. Для каждой строится **α-отсечение** → интервал **[A, B]** и длина **L**.
3. **k-means** по исходным величинам или по интервалам (выбор критерия расстояния).
4. Фильтры **β** (порог от max величины *M*) и **γ** (доля лидеров по *M*) согласованы с выбранным критерием; затем повторный k-means на усечённой выборке.

Подробные таблицы критериев, API и формулы — только в **Пояснительная_записка.docx** и `fuzzy-normal/docs/README.md`.
