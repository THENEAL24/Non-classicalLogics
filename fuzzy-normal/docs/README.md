# Комплекс программ: нечёткие величины с нормальной функцией принадлежности

## 1. Теоретические сведения

**Нечёткая величина** задаётся функцией принадлежности μ(x) ∈ [0, 1]. В варианте «нормальное распределение» (по справочнику Абчук В.А. и др., функция случайной величины как μ) используется гауссова форма:

\[
\mu(x) = \exp\left(-\left(\frac{x-a}{\sigma}\right)^2\right),
\]

где **a** — центр (математическое ожидание носителя), **σ > 0** — параметр размытости (аналог среднеквадратичного отклонения).

Практический **носитель** принимается на отрезке [a − 3σ, a + 3σ].

### Операции (аппроксимация для независимых величин)

| Операция | Параметры результата |
|----------|----------------------|
| A + B    | a = a₁+a₂, σ = √(σ₁²+σ₂²) |
| A − B    | a = a₁−a₂, σ = √(σ₁²+σ₂²) |
| A × B    | a = a₁a₂, σ из линейной аппроксимации принципа расширения |
| A ÷ B    | a = a₁/a₂, σ — по формулам ошибок измерения |

**Сравнение:** по центроидам (для данной μ центроид = a); при равных a — по «определённости» (меньшая σ считается «больше»).

**Расстояние** для кластеризации: евклидово в пространстве (a, σ) с весом для σ.

## 2. Состав комплекса

| Компонент | Путь | Назначение |
|-----------|------|------------|
| Библиотека нечётких величин | `pkg/fuzzy` | тип, μ(x), операции, множество, генерация, журнал |
| Библиотека кластеризации | `pkg/cluster` | k-means по выбранному критерию |
| HTTP API | `cmd/server` | REST, раздача статики |
| Веб-интерфейс | `web` | React (Vite), минималистичный UI |

Библиотеки **не зависят от GUI** и могут подключаться из других программ Go:

```go
import (
    "fuzzy-normal/pkg/fuzzy"
    "fuzzy-normal/pkg/cluster"
)
```

## 3. Порядок использования

### Требования

- Go 1.22+ и Node.js 20+ (для локальной разработки фронта)
- Docker и Docker Compose (для развёртывания одной командой)

### Запуск (Docker)

```bash
cd fuzzy-normal
docker compose up --build
```

Браузер: http://localhost:8080

### Локально

```bash
go test ./...
cd web && npm install && npm run build && cd ..
STATIC_DIR=./web/dist go run ./cmd/server
```

### Интерфейс (вкладки)

1. **Операции** — ввод двух величин (a, σ), сложение, вычитание, умножение, деление, сравнение.
2. **Множество** — генерация 100–300 элементов, просмотр, сохранение в JSON.
3. **Кластеризация** — K и критерий; **β/γ** по той же величине, что и k-means (a или σ; L, A·B или m·L), live-пересчёт.
4. **μ(x)** — вычисление степени принадлежности в точке.
5. **Журнал** — операции дублируются в `fuzzy_journal.log`.

### Пример использования библиотеки

```go
a := fuzzy.MustNew(10, 2)
b := fuzzy.MustNew(5, 1.5)
sum := fuzzy.Add(a, b)
set, _ := fuzzy.GenerateSet(fuzzy.GenOptions{Count: 200, MeanMin: 0, MeanMax: 50, SigmaMin: 0.5, SigmaMax: 5, Seed: 42})
res, _ := cluster.KMeans(set, cluster.Config{K: 4, Criterion: cluster.ByMeanAndSigma})
_ = sum
_ = res
```

## 4. Нечёткие величины как параметры кривых

Сначала генерируется **N** нечётких величин N(a, σ) (например, 150). Каждая такая величина — **не абстрактная запись**, а **параметры одной кривой** μ(x)=exp(−((x−a)/σ)²). Итого: **N величин → N кривых**.

## 5. α-отсечение и интервалы [A, B]

1. Для **каждой** из N пар (a, σ) строится своя кривая μ(x) на [a−3σ, a+3σ], **нормализация** μ̂(x)=μ(x)/max μ.
3. Задаётся **критерий α** ∈ (0, 1]. Множество **{x | μ(x) ≥ α}** для гауссовой μ — симметричный интервал **[A, B]**:
   - A = a − σ√(−ln α), B = a + σ√(−ln α) (с отсечением по носителю).
4. Интервал **[A, B]** трактуется как **отдельная нечёткая величина-плато** (μ=1 на [A,B], 0 вне).
5. Сами интервалы **кластеризуются** (k-means по L, по (A,B) или по середине и L). Опционально **фильтр β** по длине L отсекает «узкие» интервалы перед повторным разбиением на кластеры.

Вкладка UI: **«α → [A,B]»**.

## 6. Кластерный анализ N(a, σ)

**k-means** по исходным величинам: K и критерий (a или a и σ). Вкладка **«Кластеры N»**.
